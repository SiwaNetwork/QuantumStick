# TimeStick Windows Implementation

Полная реализация драйвера и web интерфейса для TimeStick устройств под Windows 11.

## Обзор реализации

### 1. Windows Драйвер (windows_driver/)

Полнофункциональный Windows драйвер, реализованный с использованием Windows Driver Framework (WDF):

#### Компоненты:
- **timestick_windows.h** - Заголовочный файл с API определениями
- **timestick_driver.c** - Основной код драйвера ядра
- **timestick_usermode.c** - Пользовательская библиотека для API
- **timestick.inf** - INF файл для установки драйвера
- **Makefile** - Система сборки

#### Функциональность:
- USB устройство поддержка (VID_0B95, PID_1790/1791/1792)
- IOCTL интерфейс для взаимодействия с пользовательскими приложениями
- PTP (Precision Time Protocol) поддержка
- Сетевая статистика в реальном времени
- Управление энергопотреблением
- Автоматическое обнаружение и настройка устройства

### 2. Web Интерфейс с Windows Поддержкой

Расширенный web интерфейс с платформо-специфичными функциями:

#### Новые модули:
- **windows_support.py** - Модуль поддержки Windows
- **Обновленный app.py** - Добавлена поддержка множественных платформ
- **Расширенный HTML** - Новая секция платформы и Windows контролы

#### Windows-специфичные функции:
- Автоматическое обнаружение устройств через WMI/PowerShell
- Установка драйвера через web интерфейс
- Управление PTP через Windows API
- Получение системной информации Windows
- Мониторинг производительности

### 3. API Endpoints

Новые REST API endpoints для Windows функций:

```
GET  /api/platform          - Информация о платформе
GET  /api/devices/detect    - Обнаружение устройств
GET  /api/network/interfaces - Сетевые интерфейсы
POST /api/driver/install    - Установка драйвера
POST /api/ptp/control       - Управление PTP
GET  /api/status/complete   - Полный статус устройства
```

## Установка и использование

### Windows

1. **Сборка драйвера:**
   ```cmd
   cd windows_driver\build
   make all
   ```

2. **Установка:**
   ```powershell
   .\install_timestick.ps1
   ```

3. **Запуск web мониторинга:**
   ```cmd
   cd web_monitor
   pip install -r requirements.txt
   python app.py
   ```

### Linux (существующая функциональность)

```bash
cd web_monitor
make install
make start
```

## Troubleshooting

### Частые проблемы:

1. **Драйвер не устанавливается**
   - Проверьте права администратора
   - Включите test signing mode
   - Проверьте цифровую подпись

2. **Устройство не обнаруживается**
   - Проверьте USB подключение
   - Обновите USB драйверы
   - Перезагрузите компьютер

3. **Web интерфейс не работает**
   - Проверьте зависимости Python
   - Убедитесь в доступности порта 8080
   - Проверьте права файловой системы
